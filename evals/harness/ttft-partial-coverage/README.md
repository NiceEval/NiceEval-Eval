# TTFT 的部分覆盖

## 项目

`repo/` 的部分 agent 运行带 OTel model span，另一些 adapter 没有采集同一类证据。因此首 token 延迟
在数据中真实存在，但只覆盖一部分 experiment；这是“有数据”和“全量可比”之间的典型边界。

项目仍是只读历史快照，不允许通过重跑补齐观测数据。

## 希望测试的内容

- agent 是否使用 `show` 的执行或时间切片查模型调用证据；
- 是否指出 Claude DP V4 系列有 TTFT，而 Bub / Codex 系列没有；
- 是否拒绝为缺少观测的 experiment 计算平均值或按邻组推断；
- 是否把“未采集”与“延迟为零”明确区分。

这题比完全不存在的指标更难：局部命中会诱使 agent 过度概括。
