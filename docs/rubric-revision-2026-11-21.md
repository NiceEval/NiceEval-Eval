# 2026-11-21 判据修订

依据同日的《rubric-audit：判据质量审计》。下表引用该报告的章节和可通过 NiceEval 公开 CLI 复查的历史 Attempt。历史分数保留原判据版本。以下修订改变了得分条件，即使满分相同，新旧得分也不可直接比较。候选对比须按同一版判据重建基线。

| 题目与判据 | 修订 | 审计依据 |
| --- | --- | --- |
| DB-GPT 真实响应映射 | 真实 DB-GPT 响应 body 的业务内容映射占 4 分，完整解析所选协议占 2 分。非流式 JSON 核对最终内容，流式接口核对对应事件与正常结束。mock、echo、未读 body 或日志冒充回复均不得分。 | B2。历史 `@1TQ699P8CYFZN` 的 JSON 内容映射正确，但未实现题面未要求的 SSE，原判据给了 0/6。 |
| DB-GPT 真实负例 | 实际缺表或缺列且收到真实业务响应占 1 分，断言业务拒绝编造占 2 分，输入不泄露缺失事实或标准答案占 1 分。允许先查 schema、缺失时勿编造的通用指令。数值和 SQL 分别按已观测到的输出核对。 | B1。历史 `@1HTHDA19AXW39` 和 `@1TQ699P8CYFZN` 的条件性指令含义相近，原判据对它们给出相反结论。 |
